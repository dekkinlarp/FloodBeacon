Images are noncommercial research/demo derivatives. Source URLs, acquisitions, original and output checksums, source CRS and processing are recorded per image in ../bridge-catalog/catalog.json. Web Mercator warps preserve source validity masks. Review comparisons use nearest-neighbour crop zooms. Manual annotations are not automated detection or surveyed damage extents.
